# 刘同学雅思阅读Heading题课后复习计划

- 生成日期：2026-05-29
- 使用对象：老师发给学生使用
- 单次时长：每次 10-20 分钟

## 核心复习点

- 本节课训练雅思阅读 heading 题，也就是为段落找标题。
- heading 题找的是段落中心，不是信息匹配里的微观细节。
- 观点可能来自个人言论、事实陈述、转折后内容、总结句或下一段开头的承上启下。
- for example、for instance、because、according to、数据、具体例子多数只是论据。
- 不能机械只看首尾句；现在的 heading 更要求真正识别观点。
- 一个段落可能有不止一个观点，选项通常只对应其中一个可匹配观点。
- 嗅觉与记忆文章中，unreliable evidence、bring back memories、escape the past 等选项要看是否在观点位置出现。

## 复习节点

### 第1天

- 复习重点：第一次整课回放，先分清 heading 和信息匹配。
- 目标：能说出 heading 找中心，信息匹配找细节。

填空题：
- Heading 题找的是段落____________，不是一句细节。（答案：中心）
- 信息匹配常找微观内容，heading 更看重____________。（答案：观点）
- states、claims、argues、引号常提示个人____________。（答案：言论）
- 事实类陈述也可能是段落____________。（答案：观点）
- for example / for instance 常提示后面是____________。（答案：例子）
- because / due to 后面常是解释，不一定是____________。（答案：中心）
- according to 和大量数据通常优先当作____________处理。（答案：细节）
- 每段 heading 都会考，没有信息匹配那种____________。（答案：NB）

选择题：
- heading 题最核心的任务是什么？（答案：A）
- argues 在阅读观点句里常等于什么？（答案：A）

课堂原话：
- heading 要找的永远都是最重要的那个观点。
- 不是没有提到，而是它并非观点。

### 第2天

- 复习重点：第二次整课复习，重点练观点与例子的边界。
- 目标：看到例子、解释、数据时能判断是否需要跳过。

填空题：
- 论据只是 supporting topic sentence，通常不是____________。（答案：答案）
- say 有时等于 for example，提示后面是____________。（答案：举例）
- 如果 evidence 只在例子中出现，不一定能选 checking unreliable ____________。（答案：evidence）
- conclude 后面通常更可能是____________。（答案：观点）
- but 后内容即使看起来微观，也可能是____________转折。（答案：核心）
- 比较两个具体类目时，通常已经进入____________层面。（答案：细节）
- 不能因为一个词被提到，就认为它是段落____________。（答案：中心）
- 读 heading 时要坚定找观点，不要回头把____________当观点。（答案：例子）

选择题：
- 为什么某段提到 unreliable evidence 却不一定选 F？（答案：A）
- 看到 conclude 时通常应该怎样？（答案：A）

课堂原话：
- 不是没有提到，而是它并非观点。
- 例子里面再怎么样都不重要。

### 第7天

- 复习重点：一周后迁移，集中训练复杂段落里的多观点识别。
- 目标：能接受一个段落不止一个观点，并从选项里找能对应的那个。

填空题：
- 如果下一段开头 this problem 指代上一段，上一段中心可能与____________有关。（答案：problem）
- 一个段落可能有多个____________，不能主观只认一个。（答案：观点）
- 选项通常只给一个能与段落观点____________的标题。（答案：对应）
- travel 段落可能考 history，也可能考 importance，要看选项____________。（答案：匹配）
- apparently incompatible characteristics 表示看似____________的特点。（答案：不兼容）
- but 后面的 surprising course title 即使具体，也可能是____________。（答案：答案）
- 观点很散时，先把每个可能观点____________列出来。（答案：独立）
- heading 不是要求把所有细节读懂，而是抓住可匹配的____________。（答案：中心）

选择题：
- 下一段开头 this / these 有什么价值？（答案：A）
- 一个段落多个观点时该怎么选？（答案：A）

课堂原话：
- 一个段里面也不一定只有一个观点。

### 第14天

- 复习重点：两周后校准，重点辨析嗅觉文章中的相似选项。
- 目标：能区分视觉与嗅觉的伴随、对比、不可靠证据和逃离过去。

填空题：
- sense 可表示感官，不只是____________。（答案：意识）
- scent / aroma 表示____________。（答案：气味）
- image 属于视觉，scent 属于____________。（答案：嗅觉）
- reinforcing one sense with another 强调两种感官____________。（答案：伴随）
- scent versus image 强调两种感官____________。（答案：对比）
- escaping from reliving the past 表示逃离____________。（答案：过去）
- checking unreliable evidence 里的 checking 强调____________动作。（答案：验证）
- 同一篇文章都在讲嗅觉，不能看到气味就____________。（答案：乱选）

选择题：
- A 与 D 都可能出现两种感官，区别是什么？（答案：A）
- checking unreliable evidence 的核心动词是什么？（答案：A）

课堂原话：
- 没有在观点里面找到内容，不要回去把例子当成观点。

### 第30天

- 复习重点：一个月后总复盘，用一篇完整 heading 题检验观点识别。
- 目标：能在限时中完成读选项、找观点、排除例子和错题归因。

填空题：
- 长期流程：先读 heading 选项，再回段落找____________。（答案：观点）
- 观点信号包括个人言论、事实陈述、转折、总结和____________指代。（答案：下段）
- 例子和数据只在其他题型需要时才可能细看，heading 中先____________。（答案：跳过）
- 看到关键词被提及，要问它是不是在____________位置。（答案：观点）
- 选项区别要提前拆开，例如伴随、对比、验证、____________过去。（答案：逃离）
- 错题常见原因之一是把____________当中心。（答案：例子）
- 第二类错因是只看首尾，没有看转折或____________句。（答案：总结）
- 最终目标是用观点对应标题，而不是把全文逐句____________。（答案：翻译）

选择题：
- heading 错题最常见的复盘角度是什么？（答案：A）
- 一个月后最该留下的阅读动作是什么？（答案：A）

课堂原话：
- heading 要找的永远都是最重要的那个观点。
- 没有在观点里面找到内容，不要回去把例子当成观点。

## 最后提醒

- Heading 题找段落中心，不找零散细节。
- 观点可能在个人言论、事实陈述、转折、总结或下一段指代里。
- for example、because、according to、数据通常先当细节。
- 一个段落可能有多个观点，选项能对应哪个就选哪个。
- 提到不等于答案，必须看是否在观点位置。
- 错题按没找观点、把例子当观点、选项区别没分清来复盘。
