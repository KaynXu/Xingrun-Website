# RCF-002 总览浮层筛选器

**英文名:** Overview Floating Filter

## 使用效果

一个短标签挂在总览标题旁边，例如 `全校区`。鼠标放上去或点击后出现第一层筛选标签，再 hover 或点击第一层标签时，在下方出现第二层选项。选中后入口文字变成 `全校区：科目：数学 / 年级：七年级`，并带 `x` 可一键清空。

可交互预览：

```text
docs/ricardo-components/lab/index.html
```

## 适用场景

- 校区总览。
- 仪表盘顶部统计卡片的范围筛选。
- 标题旁边需要轻量筛选入口的区域。

## 调用前必须确认

- 入口文字：例如 `全校区`。
- 层级数量：通常为 2 层。
- 第一层内容：例如 `科目 / 教师 / 学段 / 年级`。
- 第二层内容：每个标签下的具体选项。
- 选中后入口显示格式。
- 是否支持 hover 展开。
- 是否支持点击展开。
- 光标离开后关闭的范围。
- 是否允许一键清空。

## 当前落地口径

- 入口文字：`全校区`。
- 第一层：`科目 / 教师 / 学段 / 年级`。
- 科目固定为：`数学 / 物理 / 国际数学`。
- 第二层只在 hover 或点击第一层后出现。
- 再次点击已打开的第一层标签时，第二层关闭。
