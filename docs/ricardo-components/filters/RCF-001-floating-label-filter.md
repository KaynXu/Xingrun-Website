# RCF-001 浮层标签筛选器

**英文名:** Floating Label Filter

## 使用效果

一排筛选标签显示在页面内容区顶部。鼠标放上去或点击某个标签时，下方出现选项框。选择后标签显示已选内容，并带 `x` 可取消。多个标签可以逐步缩小范围。

可交互预览：

```text
docs/ricardo-components/lab/index.html
```

## 适用场景

- 班级管理筛选。
- 学员管理筛选。
- 课程日历筛选。
- 其他需要多个条件逐步缩小范围的列表页面。

## 可选配置

- 标签可配置左侧图标，用于工具型页面强化识别。
- 可隐藏右侧范围标签，例如不显示 `课程卡片`。
- 可隐藏底部筛选摘要说明，让筛选卡片更紧凑。
- 可启用悬浮选项框，让下方选项不占据页面高度；用于课程日历这类需要左侧时间栏稳定对齐的页面。
- 启用悬浮选项框时，关闭要有短延迟，避免鼠标从标签移动到选项框时误关；课程日历当前使用 80ms。

## 调用前必须确认

- 入口文字：例如 `筛选`。
- 层级数量：通常为 2 层。
- 第一层内容：例如 `科目 / 教师 / 学段 / 年级`。
- 第二层内容：每个标签下的具体选项。
- 选项联动逻辑：例如先选数学后，教师只显示数学老师。
- 是否支持 hover：电脑端通常支持。
- 是否支持点击：Pad 和手机端需要支持。
- 选择后是否关闭选项框。
- 是否显示范围标签：例如 `全机构班级`、`仅本人班级`。
- 是否需要紧凑模式：隐藏范围标签和底部说明。
- 是否需要选项框悬浮：不占页面高度，适合课程日历。
- 是否有额外搜索框：例如 `学员姓名查询`，该搜索框不属于筛选标签本身。

## 当前落地口径

- 班级管理：`科目 / 教师 / 学段 / 年级`。
- 学员管理：`科目 / 教师 / 学段 / 年级 / 班级`。
- 课程日历：`科目 / 教师 / 学段 / 年级`，启用标签图标、紧凑模式和悬浮选项框。
- 学员姓名查询作为额外搜索配置，不加入筛选标签逻辑。
