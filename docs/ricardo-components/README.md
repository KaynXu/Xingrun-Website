# Ricardo 的组件库

这是 Ricardo 在本机使用的组件记录库，暂时不接入星润正式组件库。

它用来保存已经确认过的完整交互逻辑。以后需要复用时，可以直接说组件编号或中文名，不需要重新描述整套规则。

## 查看使用效果

打开本地预览页：

```text
docs/ricardo-components/lab/index.html
```

里面有可点击、可 hover 的组件效果草稿。

## 编号规则

- `RCF`：Ricardo Component Filter，筛选类组件。
- 后续可扩展：
  - `RCC`：卡片类组件。
  - `RCForm`：表单类组件。
  - `RCN`：导航类组件。

## 调用约定

当使用组件库里的筛选组件时，需要先确认：

- 入口文字是什么。
- 有几层。
- 每层里有什么筛选项。
- 每个筛选项的选项来源是什么。
- 是否支持 hover 展开。
- 是否支持点击展开。
- 选择后是否关闭浮层。
- 是否有权限差异。
- 是否有额外搜索框。
