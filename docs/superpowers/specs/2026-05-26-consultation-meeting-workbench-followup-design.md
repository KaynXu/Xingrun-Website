# 面对面咨询工作台后续处理设计

日期：2026-05-26

## 目标

优化咨询端的面对面模式，让老师在现场核对咨询记录时更快完成“已核对/已处理”的队列管理，同时保留原有页面风格、原有卡片结构和原有流程图视觉。

本次范围还包括桌面端左侧导航收起后的图标名称提示。

## 保持不变

- 面对面工作台仍使用现有浅蓝容器、白色卡片、顶部工具栏和咨询流程图样式。
- 主标签仍是 `待处理 / 已处理`。
- 详情/编辑弹窗仍使用现有咨询表单。
- 面对面卡片不新增其他流程节点，也不重画流程图。

## 主次筛选层级

`待处理 / 已处理` 是一级导航，保留当前大按钮视觉。

一级导航下方新增更轻的二级筛选栏，避免和主标签长得一样：

- 二级状态筛选：`待咨询 / 已结束`
- 时间筛选：仅在 `已结束` 二级筛选下显示 `一周内 / 一月内 / 30天+`

二级筛选全部使用点击式 chips 或轻量按钮，不使用下拉。

## 待处理分组

待处理页内拆成：

- `待咨询`：尚未进入终态的记录。
- `已结束`：已经是 `成功进班` 或 `咨询结束` 的记录，但还没有在本次面对面工作台里核对完成。

`待处理 > 已结束` 也要支持时间筛选：

- `一周内`
- `一月内`
- `30天+`

筛选依据是咨询的结束时间。

## 已处理分组

已处理页继续保留：

- `待咨询`
- `已结束`

二级筛选 UI 与待处理页保持一致，但仍明显弱于一级 `待处理 / 已处理` 标签。

已处理页用于查看本次面对面工作台里刚核对过的记录。

## 结束时间

新增咨询结束时间概念，用于面对面工作台的已结束时间筛选。

记录进入以下状态时写入结束时间：

- `成功进班`
- `咨询结束`

如果记录已经有结束时间，后续没有再次明确改变终态时不反复刷新。

历史上已经是 `成功进班` 或 `咨询结束` 的旧数据，如果没有结束时间，统一归入 `30天+`。

用户后续手动改变是否 `OVER` 或重新进入终态时，再写入新的结束时间，并按新结束时间进入对应筛选区间。

## 直接标记已处理

待处理卡片新增一个按钮，放在编辑按钮右侧。

作用：不用打开编辑弹窗，也不改变咨询状态，直接把这张卡标记为本次面对面工作台的已处理。

行为：

- 只影响面对面工作台本地队列。
- 不修改 `flow_stage`。
- 不修改 `completed_stages`。
- 不修改咨询内容、备注、老师、班级等业务字段。
- 页面保持在当前 `待处理` 视图，不自动跳到 `已处理`。
- 这张卡从当前列表离开时加入轻动画。

按钮文案和图标应表达“已核对/已处理”，避免误解为进入待处理。

## 处理动画

当卡片被处理时，包括直接标记已处理、编辑弹窗保存后进入已处理、双击 `OVER` 后离开当前分组，卡片应有轻量动画：

- 短暂高亮或边框提示。
- 淡出。
- 高度折叠。

动画只用于反馈，不改变数据语义。

在用户开启减少动态效果时，动画降级为即时列表更新或极短淡出。

## 面对面流程图交互

面对面卡片里的流程图参考主页面流程图逻辑，但交互范围收窄：

- 只有 `OVER` 节点允许双击。
- 双击其他流程节点不推进流程、不补亮节点、不改变状态。
- `OVER` 双击后直接把记录设为 `咨询结束`。
- 这次改变要记录结束时间。
- 原有 `completed_stages` 保持不变，不自动补亮客服微信、教师微信、沟通、测试、试听等节点。

这表示现场可以快速把该咨询判定为失败/结束，同时不破坏它此前真实走过的流程。

## 教师筛选

面对面工作台顶部教师筛选不再使用下拉选择。

新交互：

- 顶部显示一个教师筛选按钮。
- 默认状态为 `全部教师`。
- 点击按钮后弹出一个小卡片。
- 卡片中按 `数学` 和 `物理` 两类展示教师 chips。
- 点击某位教师后立即筛选。
- 再次点击已选教师或点击 `全部教师` 可回到默认全部教师。
- 如果页面出现课程或班级筛选，必须跟随教师筛选联动：先选教师，再只展示这个教师绑定的班级；不选教师时默认展示全部教师和全部班级。
- 课程或班级筛选同样使用点击式 chips 或弹出卡片，不使用普通下拉。

当前教师接口没有固定科目字段，因此第一版按当前咨询记录的 `consultation_subject` 归类教师：

- 老师有数学咨询记录，显示在 `数学` 类。
- 老师有物理咨询记录，显示在 `物理` 类。
- 同一老师两类都有记录时，可在两类都出现。
- 默认 `全部教师` 不受归类影响，仍覆盖所有记录。

如果后续需要管理教师固定科目，再单独增加教师科目配置，不放进本次实现。

## 左侧导航收起提示

桌面端在 `咨询记录` 和 `课程日历` 等页面会使用 compact 左侧导航，当前只显示图标。

新增行为：

- 仅在桌面 compact 状态启用。
- 鼠标悬停到图标时，立刻在图标右侧显示页面名称。
- 键盘 focus 到图标时也显示页面名称。
- 展开状态不显示额外 tooltip。
- 移动端抽屉导航不变。

tooltip 应使用现有浅色/深色主题风格，不能遮挡当前图标，也不能影响导航点击。

## 数据与兼容

需要新增或复用字段记录咨询终态时间。该字段应随咨询记录 API 返回给前端。

面对面工作台的“本次已处理”仍是前端本地会话状态，最终保存后同步业务字段；直接标记已处理不会产生需要最终保存的业务修改。

历史数据兼容规则：

- 没有结束时间且处于终态的记录归入 `30天+`。
- 没有结束时间且非终态的记录按 `待咨询` 展示。
- 旧记录的流程亮灯仍按现有兼容逻辑展示，不自动补亮。

## 测试重点

实现时需要覆盖：

- 待处理页二级筛选能区分 `待咨询 / 已结束`。
- 待处理已结束列表按结束时间分为 `一周内 / 一月内 / 30天+`。
- 历史终态但无结束时间的记录归入 `30天+`。
- 直接标记已处理不修改业务字段，只移动本地队列。
- 编辑保存后仍停留在待处理视图。
- 面对面流程图只有 `OVER` 双击有效。
- 双击 `OVER` 后状态为 `咨询结束`，结束时间被写入，其他流程节点不被自动补亮。
- 教师筛选使用点击式弹出卡片，不使用 select 下拉。
- 教师筛选默认 `全部教师`，点击数学/物理分类下的教师后立即筛选。
- 课程或班级筛选跟随教师筛选联动，选定教师后只展示该教师绑定的班级。
- compact 左侧导航 hover/focus 显示页面名称。

## 暂不做

- 不重做主咨询页流程图。
- 不改变咨询主页面已有时间筛选逻辑。
- 不新增完整的教师科目管理后台。
- 不记录每次面对面处理的历史流水。
- 不把直接标记已处理写入后端持久状态。
