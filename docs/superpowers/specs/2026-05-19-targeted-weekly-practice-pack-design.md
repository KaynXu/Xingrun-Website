# 定向一周错题练习包设计

日期：2026-05-19

## 背景

当前网页智能错题里的每周练习跟进把两个动作分开：

- `批量生成未生成学生练习`
- `下载本周练习合集`

实际使用中，老师的目标不是先管理一个“本周练习状态”，而是想基于某个复习目标，直接拿到一份可以发给学生或家长的练习包。因此新方案把这两个动作合并为一个主流程：老师选择复习方向和题量档位后，系统为班级学生生成接下来一周要完成的错题练习包，并下载班级 zip。

## 核心结论

采用“目标导向 + 混合式异步生成 + 真实错题优先 + AI 同错因变式补题”的方案。

老师在智能错题页面选择：

- 复习方向类型：`按专题/知识点` 或 `按错因`
- 具体方向：例如 `解方程`、`几何`、`粗心`、`去分母漏乘`
- 题量档位：`轻量 5题`、`标准 10题`、`强化 15题`

点击主按钮：

```text
生成并下载一周练习包
```

系统为当前班级逐个学生生成一份 PDF，最后打包成一个 zip。每个学生 PDF 前半部分是接下来 7 天的练习安排，最后附答案与关键步骤页。

## 第一版范围

第一版做这些能力：

- 合并当前“批量生成”和“下载合集”为一个主入口。
- 不再把选题限制在当前周上传的错题。
- 支持按 `专题/知识点` 或 `错因` 选择复习方向。
- 支持 `轻量 / 标准 / 强化` 三档题量。
- 对每个学生优先选择匹配方向的历史真实错题。
- 真实错题不足时，AI 基于真实题和错误原因生成同错因变式题补足。
- 不跨方向补题：选择 `去分母漏乘` 时，不自动补 `审题` 或 `符号`。
- 将题目分配到接下来 7 天。
- 每个学生 PDF 最后附答案页，包含标准答案、关键步骤、易错提醒。
- 整班生成一个 zip，包含每个成功学生的一份 PDF。
- 采用混合式异步体验：短时间轮询，完成则自动下载，未完成则显示稍后下载。

第一版不做：

- 自动定时生成。
- 自动群发给家长。
- 学生完成打卡。
- 家长已读状态。
- 复杂知识图谱或难度模型训练。
- 老师在生成前手工挑选每个学生的具体题目。

## 页面体验

入口仍放在网页后台 `智能错题` 的练习跟进区域。

页面顶部保留班级选择，并新增三个生成条件：

- `复习方向类型`
  - `按专题/知识点`
  - `按错因`
- `具体方向`
  - 按专题/知识点时，优先来自已有 `topic_category` 和未来可扩展的知识点标签。
  - 按错因时，优先来自现有错因分类和老师常用错因短语。
- `题量档位`
  - `轻量 5题`
  - `标准 10题`
  - `强化 15题`

主按钮为：

```text
生成并下载一周练习包
```

点击后页面进入生成状态：

- 如果任务很快完成，自动下载 zip。
- 如果任务仍在生成，显示 `正在生成，完成后可下载`。
- 如果已有同条件未完成任务，继续展示该任务状态，避免重复提交。
- 如果已有同条件已完成任务，显示 `下载` 和 `重新生成`。

学生卡片可展示：

- 生成状态：待生成、生成中、已完成、失败、无匹配错题。
- 本次练习题数。
- 真实错题数量。
- AI 变式题数量。
- PDF 下载入口。
- 失败原因。

## 选题规则

候选池不再使用“本周上传”作为主限制。

候选真实错题来自学生历史有效错题：

- 来源为本地微信错题。
- 已识别完成。
- 未被硬删除。
- 未掌握错题优先。
- 已掌握题可按复现规则进入候选。
- 默认仍排除超过 6 个月的日常练习候选，除非后续增加历史范围选项。

按方向过滤：

- `按专题/知识点`：优先匹配 `topic_category`，后续可扩展到更细的知识点字段。
- `按错因`：匹配顶层错因、二级错因摘要、孩子错因文本、老师备注中的目标短语或归一化标签。

排序优先级：

1. 与目标方向匹配程度高。
2. 未掌握优先于已掌握复现题。
3. 最近没有进入练习单的题优先。
4. 易反复错题优先。
5. 较新的有效错题优先。

## AI 同错因变式题

当某个学生匹配方向的真实错题不足以达到题量档位时，系统使用 AI 生成同错因变式题补足。

AI 生成不是随机改题，而是围绕目标错误原因生成训练题。例如原错因是：

```text
解方程去分母时，等式右边没有同乘最小公倍数。
```

则 AI 变式题必须专门考察：

```text
去分母时等式两边每一项都要同乘。
```

每道 AI 变式题必须返回：

- 题目正文。
- 来源错题 ID 或来源错因摘要。
- 训练目标。
- 标准答案。
- 关键步骤。
- 易错提醒。
- 难度估计。

AI 变式题不得：

- 换成其它错因。
- 直接泄露到学生练习题正文里。
- 生成无法求解或答案不唯一的题。
- 生成超出原学生学习阶段明显过多的内容。

## 质量控制

AI 变式题生成后需要审稿。

审稿目标：

- 题目可解。
- 标准答案与题目一致。
- 关键步骤能支撑答案。
- 确实考察本次目标方向。
- 不混入其它错因。
- 不在学生练习区泄露答案。

第一版审稿采用 AI 审稿为主。对于可规则校验的题型，例如解方程、计算题，后续可以增加程序化校验，但不作为第一版前置要求。

审稿失败时：

- 对该学生重新生成一次变式题。
- 重试后仍失败，则该学生 PDF 可以少于目标题量，并在答案页或 zip 说明中标注未补足原因。

## 一周分配规则

每个学生 PDF 将题目安排到接下来 7 天。

题量档位：

- `轻量 5题`：优先安排 5 天，每天 1 题，保留 2 天复盘或休息。
- `标准 10题`：每天 1 到 2 题。
- `强化 15题`：每天 2 到 3 题。

分配原则：

- 每天题量尽量均衡。
- 真实错题优先排在前半周。
- AI 变式题优先跟在对应真实错题之后，形成“原错题 -> 同错因变式”的练习节奏。
- 如果某学生题量不足，仍按已有题分配，不跨方向补题。

## PDF 输出

每个学生生成一份 PDF。

学生 PDF 结构：

1. 封面信息
   - 学生姓名。
   - 班级。
   - 复习方向。
   - 题量档位。
   - 生成日期。
2. 7 天练习安排
   - 每天列出当天题目。
   - 真实错题保留原题来源和必要图片。
   - AI 变式题标记为“同类巩固题”，不对学生暴露 AI 生成痕迹。
3. 每题反思区
   - 错因填空。
   - 改进提醒填空。
4. 答案页
   - 标准答案。
   - 关键步骤。
   - 易错提醒。

zip 结构：

```text
班级名-生成日期-一周错题练习包.zip
├── 王睿博-一周错题练习.pdf
├── 毛裕宁-一周错题练习.pdf
├── 邹欣彤-一周错题练习.pdf
└── 打包说明.txt
```

`打包说明.txt` 只在存在失败、跳过或题量不足时生成。

## 后端数据设计

新增“练习包任务”概念，避免把整个班级 zip 生成塞进普通请求。

建议新增表：

- `wrong_question_practice_pack_jobs`
  - id
  - organization_id
  - class_id
  - created_by
  - mode: `topic` 或 `reason`
  - target: 具体方向
  - volume: `light`、`standard`、`intensive`
  - status: `pending`、`running`、`ready`、`partial_failed`、`failed`
  - zip_path
  - generation_error
  - created_at
  - updated_at

- `wrong_question_practice_pack_job_students`
  - id
  - job_id
  - student_id
  - student_name_snapshot
  - status
  - requested_question_count
  - real_question_count
  - variant_question_count
  - pdf_path
  - generation_error

现有 `wrong_question_practice_sheets` 可以继续作为单学生练习单记录来源。第一版可以选择：

- 为每个学生仍创建一条 `wrong_question_practice_sheets`，并扩展支持 AI 变式题和一周分配。
- 或新增 pack 专属学生 PDF 数据结构。

推荐第一版复用 `wrong_question_practice_sheets` 的 PDF 渲染和权限模型，同时新增 pack job 管理整班任务和 zip。

## 后端接口

建议新增：

```text
POST /api/wrong-question-practice-packs
```

创建整班练习包任务。请求参数：

- class_id
- mode
- target
- volume

返回：

- job_id
- status

```text
GET /api/wrong-question-practice-packs/<job_id>
```

查询任务状态、每个学生状态和下载地址。

```text
GET /api/wrong-question-practice-packs/<job_id>/download
```

下载 zip。仅当任务 ready 或 partial_failed 时可下载。

```text
POST /api/wrong-question-practice-packs/<job_id>/regenerate
```

重新生成同条件任务。第一版可先不做，页面只保留未来入口。

## 混合式异步体验

点击主按钮后：

1. 前端提交 `POST /api/wrong-question-practice-packs`。
2. 后端创建 job 并启动后台生成。
3. 前端短时间轮询 job 状态。
4. 如果状态变为 `ready` 或 `partial_failed`，自动打开下载地址。
5. 如果超出短轮询时间仍未完成，页面保留任务卡片和下载按钮。

建议第一版短轮询 20 到 30 秒。之后不再卡住页面。

## 扣费与幂等

AI 生成变式题和 AI 审稿会产生额外成本。

第一版扣费建议：

- 真实错题改造成练习题沿用现有错题练习生成扣费。
- AI 变式题按学生维度或题目维度计入同一个练习包 job。
- 同一个 job 内要有 request identity，避免刷新页面重复扣费。

幂等规则：

- 同一用户、同一班级、同一 mode、target、volume，如果存在未完成 job，优先返回已有 job。
- 已完成 job 默认允许下载。
- 老师明确点重新生成时才创建新 job。

## 错误处理

班级级错误：

- 未登录、无权限、参数不合法、API Key 缺失，直接返回错误。
- 后台任务整体异常，job 标记为 `failed`。

学生级错误：

- 该学生没有匹配方向错题：标记为 `skipped`。
- AI 变式题生成失败：允许少题或标记该学生失败。
- PDF 生成失败：标记该学生失败。

zip 规则：

- 至少一个学生 PDF 成功时，生成 zip，job 为 `partial_failed` 或 `ready`。
- 没有任何学生 PDF 成功时，job 为 `failed`。
- 失败、跳过、题量不足写入 `打包说明.txt`。
