# 每周错题跟进助手设计

日期：2026-05-04

## 背景

老师希望每周把学生错题整理后主动发给家长。系统不做小程序订阅消息推送，避免个人版小程序权限、模板审核和授权续期带来的复杂度。

这一版的产品目标是：AI 在后台把学生错题情况整理成更像老师本人发出的微信话术，老师一键复制后发给家长；同时老师可以一键下载本班所有学生错题本 PDF，方便课后跟进和群内分发。

## 第一版范围

新增一个老师端入口：每周错题跟进助手。

入口可以放在智能错题页面内，按班级和周次查看。默认展示当前周，老师也可以切换上一周。

第一版只做这些能力：

- 按班级列出本周有错题记录的学生。
- 为每个学生生成一段家长微信沟通话术。
- 支持老师一键复制单个学生话术。
- 支持老师重新生成单个学生话术。
- 支持打开或下载单个学生错题本 PDF。
- 支持一键下载本班所有学生错题本 PDF 的 zip 合集。

第一版明确不做：

- 小程序主动订阅消息推送。
- 家长已读状态。
- 学生完成打卡。
- 自动定时群发。
- 复杂复习周期和提醒规则。

## 老师端体验

页面顶部是班级和周次选择。

选中班级后，页面显示本班本周错题跟进概览：

- 本周有错题学生数。
- 本周新增错题数。
- 重点专题分布，例如计算、几何、行程。
- PDF 合集下载状态。

下方按学生展示卡片。每张学生卡包含：

- 学生姓名。
- 本周新增错题数。
- 当前错题本总题数。
- 重点专题。
- 最近上传时间。
- AI 生成的家长微信话术。
- 操作按钮：复制给家长、重新生成、查看错题本、下载 PDF。

班级顶部提供一个主按钮：下载本班错题本合集。

## 微信话术风格

话术必须像老师真实发给家长的微信，不像报告或 AI 总结。

默认风格是温和提醒：

- 使用“我看了一下”“这块还有点卡”“下次课我会再带一下”这类自然表达。
- 避免“本周错题主要集中在”“建议家长配合”“知识薄弱点”“提升能力”等报告腔。
- 不把孩子说得太严重。
- 不使用夸张表扬或模板化鸡汤。
- 每条控制在 2 到 3 小段。
- 每段适合微信直接发送。

示例：

```text
王睿博妈妈，我刚看了下孩子这周的错题，主要还是几何题读图和第一步思路容易断。

我把错题本整理好了，您让他这两天挑几道重新讲一下思路就可以，不用全刷。重点看他能不能说清楚：这题第一步为什么这么想。

下次课我这边会再帮他把这类题收一下。
```

后续可以增加三个风格选项：温和提醒、直接一点、鼓励型。第一版先默认温和提醒，不把风格选择做成必要功能。

## PDF 合集下载

老师点击下载本班错题本合集后，后端生成 zip 文件。

文件名示例：

```text
七年级5班-2026年第19周-错题本合集.zip
```

zip 内容示例：

```text
七年级5班-2026年第19周-错题本合集.zip
├── 王睿博-错题本.pdf
├── 毛裕宁-错题本.pdf
├── 邹欣彤-错题本.pdf
└── 李奕萱-错题本.pdf
```

如果某个学生 PDF 不存在或已过期，下载时先刷新该学生错题本 PDF，再写入 zip。

如果某个学生刷新失败，该学生文件不放入 zip，并在接口返回里给出失败列表。前端下载完成后显示一条轻提示，例如“3 份已打包，1 份生成失败，可稍后重试”。

## 后端设计

新增数据能力优先保持轻量，不引入完整提醒系统。

建议新增一张表：

```text
weekly_wrong_question_followup_messages
```

字段建议：

- id
- organization_id
- class_id
- student_id
- teacher_user_id
- week_start_date
- week_end_date
- style
- message_text
- source_record_ids_json
- generated_by
- created_at
- updated_at

这张表只缓存 AI 话术，避免老师每次打开页面都重新消耗 AI。

需要新增接口：

- `GET /api/wrong-question-followups/weekly?class_id=&week_start=`
- `POST /api/wrong-question-followups/weekly/messages`
- `POST /api/wrong-question-followups/weekly/messages/<id>/regenerate`
- `GET /api/wrong-question-followups/weekly/class-pdf-archive?class_id=&week_start=`

接口权限沿用智能错题权限：

- owner/admin 可以查看本机构班级。
- member 只能查看自己绑定的班级。
- 所有学生和错题记录都必须经过现有班级/老师权限过滤。

## AI 输入

生成单个学生话术时，只给 AI 必要上下文：

- 学生姓名。
- 班级名。
- 老师显示名。
- 本周新增错题数量。
- 当前错题总数。
- 重点专题。
- 2 到 3 条代表性错因摘要。
- 是否已有错题练习 PDF。

不把完整题面大量塞给 AI。完整题目已经在 PDF 里，话术只负责帮助老师自然开口。

## 错误处理

- AI 生成失败：学生卡显示“生成失败，可重试”，不影响 PDF 下载。
- PDF 刷新失败：zip 跳过该学生，并展示失败名单。
- 某学生本周无错题：不显示在默认列表。
- 班级无错题：展示空态“本周暂无需要跟进的错题”。
- 老师无权限：返回 404 或权限错误，避免泄露班级学生信息。

## 验收标准

- 老师能选择班级和周次，看到本周有错题的学生。
- 每个学生能看到自然微信话术，并能复制。
- 重新生成话术后页面展示新内容。
- 单个学生 PDF 仍能正常打开或下载。
- 班级 zip 下载后包含可生成的学生错题本 PDF。
- PDF 生成失败的学生不会导致整个 zip 失败。
- member 老师只能看到自己负责班级。
- 不出现小程序订阅消息、自动推送、已读状态相关入口。
