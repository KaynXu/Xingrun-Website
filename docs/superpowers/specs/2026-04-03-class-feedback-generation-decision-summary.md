# Class Feedback Generation Product Decision Summary

## One-Sentence Definition

“班级反馈生成”是一个独立页面，老师按任意时间范围选择班级后，系统汇总课次记录、课后反馈、老师补充备注和历史已确认反馈，生成 `班级总评 + 每位学生个性化反馈`，老师编辑确认后进入长期积累。

## Core Decisions

- 功能名确定为 `班级反馈生成`
- 不是固定每周一次，而是按 `开始日期 + 结束日期` 的任意时间范围生成
- 输出结果固定为两层：
  - 班级总评
  - 每位学生个性化反馈
- 数据来源采用“自动汇总 + 老师补充”混合模式：
  - 自动汇总当前时间范围内的课次记录、课后反馈
  - 老师补充阶段备注与学生阶段变化
- 生成后支持逐个编辑、自动保存、统一复制
- 第一版不直接发送给家长
- 只有老师最终确认稿进入长期积累，AI 初稿不进入

## Product Principle

这个功能不是单纯的 AI 写作页，而是一个“老师工作流 + AI 记忆积累”的闭环：

1. 平时教学内容持续沉淀为原始素材
2. 老师在某个阶段补充少量结构化备注
3. AI 读取素材生成反馈草稿
4. 老师编辑并确认
5. 最终确认稿进入后续 AI 积累

核心目标不是让 AI 猜得更像，而是让 AI 读到更多真实资料后写得更稳。

## Content Decisions

### Stage Notes

老师生成前补充的内容采用半结构化表单，重点包括：

- 班级整体状态
- 家长共性反馈
- 本阶段教学重点
- 下阶段预告与承接关系
- 学生阶段变化

### Student Highlight Labels

学生阶段变化标签采用：

- 系统先提供默认标签
- 老师可在此基础上新增、停用、调整顺序

标签重点用于帮助 AI 写得更具体，不是替代老师所有判断。

## History And Memory Decisions

### Historical Baseline

像 `进步明显 / 有点回落 / 变化不大` 这类比较型判断，不能只看当前阶段资料，必须先找上一条已确认反馈做基线。

查找规则：

1. 先找同粒度的上一条已确认反馈
2. 找不到再退化为最近一条已确认反馈
3. 仍找不到就禁止输出强比较结论

### Final-Only Memory Rule

只有老师最终确认后的内容进入长期积累：

- 班级总评终稿
- 学生反馈终稿

以下内容不进入记忆：

- AI 初稿
- 未确认草稿
- 中间编辑版本

## Cold Start Decisions

### Cold Start Is Normal

前几次使用时，系统必然会遇到历史资料不足，所以产品必须显式支持“冷启动 / 历史不足”场景，不能默认每个班、每个学生都已经有充分积累。

### Cold Start Strategy

冷启动时要降级的是“趋势判断”，不是“表达温度”。

这意味着：

- 不允许伪造长期趋势
- 不允许乱写“相比之前”“延续前几周趋势”
- 但仍然要保持老师对家长的自然沟通口吻

可以写成：

- “这周孩子在过去式这块没有一开始那么抗拒开口了”
- “目前孩子在阅读定位上能跟住，但完整句表达时还是容易卡一下”
- “接下来我会继续带着孩子把会做题慢慢过渡到能顺口表达出来”

不应该写成：

- “延续了前几周的趋势”
- “相比上阶段进步明显”
- “当前阶段表现稳定性不足，后续将重点提升相关能力”

也就是说，冷启动阶段的文案仍然必须像老师刚上完课，正在给家长发消息。

## Identity Decisions

- 优先绑定系统已有班级、老师、学生
- 但不强依赖预先配置完成
- 如果班级或学生未绑定完整，允许在当前流程里轻量新建
- 新建出来的对象仍然要落成正式的 `class_id / student_id`

原则是：
`优先绑定现有对象，但不把绑定当成使用门槛`

## Implementation Priority

### Phase 1

先把“能用、可信、可积累”的主链路做完整：

- 独立页面
- 选择班级与时间范围
- 汇总阶段素材
- 补充阶段备注
- 生成班级总评和学生反馈
- 逐个编辑、自动保存、统一复制
- 最终确认后进入长期积累
- 无历史时禁止强比较
- 冷启动时保持老师口吻

### Phase 2

先预埋人机协作基础，不急着直接吃录音：

- 老师上课时可轻量点击学生姓名
- 系统记录学生被点名的时间点、互动片段、重点关注对象
- 形成可与未来录音能力对齐的结构化事件时间线

这一期的目标是：
先把“课堂中老师做轻量标记”这件事跑顺。

### Phase 3

在 Phase 2 的基础上接入录音能力，走“老师轻量配合 + AI 自动提炼”的人机协作模式：

- 读取老师上课录音
- 自动转写课堂内容
- 结合老师上课时点学生姓名的标记做学生归因
- 从录音与标记中识别班级状态、学生表现、卡点和互动情况
- 进一步自动生成可信的班级总评与学生反馈草稿

这一期的核心不是“纯自动听懂一切”，而是：
老师上课时只做很轻的点名动作，AI 就能更稳地识别“刚刚在说谁、谁的状态怎样”，从而直接辅助老师写反馈。

## Decision Principles

如果后续实现时发生取舍，按以下顺序决策：

1. 先保证老师第一次就能顺利用起来
2. 先保证 AI 不乱做历史比较
3. 先保证最终确认稿能进入长期积累
4. 先保证文案像老师，而不是像系统报告
5. 先把人机协作基础打稳，再接更强的自动化能力
