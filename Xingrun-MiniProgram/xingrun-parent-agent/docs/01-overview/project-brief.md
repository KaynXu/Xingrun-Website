# Project Brief

## 项目名称

星润家长辅助 Agent

## 一句话定义

老师负责教学，Agent 负责课前预习、课后执行、错题调度、复盘提醒和家长跟进。

## 要解决的问题

- 课前没人盯预习
- 课后没人盯执行
- 错题被收集但没有回收
- 家长知道要管，但不会管
- 老师知道要跟进，但没有精力长期盯

## 核心用户

- 学生：需要明确任务和稳定节奏
- 家长：需要可执行的跟进动作，而不是泛泛建议
- 教师/机构：需要把课后管理标准化，而不是靠个人责任心硬撑

## 核心价值

- 对学生：提高完成率、复盘率、错题回看率
- 对家长：把情绪式监督变成动作式管理
- 对机构：把服务从“上课”延伸到“结果跟踪”

## 当前范围

第一阶段只做一个高价值试点：

`国际课程 / 高中 / 一对一或小班 / A-Level Business`

## 当前不做

- 一开始覆盖所有年龄段和学科
- 做大而全的通用答疑机器人
- 先做复杂技术实现，后补流程

## 成功判定

- 学生的预习、重写、错题回看形成稳定节奏
- 家长能根据模板持续跟进
- 老师输入成本可接受
- 试点里能拿到成绩稳定度或执行质量的改善证据
