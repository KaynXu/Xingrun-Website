# Core Modules

## 1. 错题系统

目标：让错题变成可回收资产，而不是堆积记录。

- 记录题目来源、知识点、错误类型、重复次数
- 按遗忘曲线安排回看
- 追踪二刷和三刷正确率

关键指标：

- 错题二次正确率
- 重复错误下降率
- 错题回看完成率

## 2. 预习推动系统

目标：把老师的材料拆成学生真的会做的预习任务。

- 每次预习控制在 10-15 分钟
- 输出固定成“看背景 + 认术语 + 做小题”
- 家长只检查完成状态和卡点

关键指标：

- 预习完成率
- 上课前后小测差异
- 上课进入状态的速度

## 3. 试卷复盘系统

目标：让每张卷子都产出行动，而不只产出分数。

- 先看结果层：总分、题型失分、波动
- 再看原因层：知识、结构、应用、时间
- 最后出行动层：下周优先修 1-3 个问题

关键指标：

- 重写完成率
- 同类题型修复率
- 周度问题收敛情况

## 4. 娱乐规划与奖励系统

目标：把“玩”纳入节奏管理，减少家庭冲突。

- 学习任务达标后解锁娱乐额度
- 奖励采用积分、时间或家庭货币
- 规则提前写清，不靠临时博弈

关键指标：

- 执行冲突频率
- 任务达标率
- 家长对规则可执行性的反馈

## 5. 教师/机构后台

目标：把跟进动作模板化，减少老师重复劳动。

- 老师上传材料和作业要求
- 系统输出家长任务和学生任务
- 周末汇总执行数据给老师和家长

关键指标：

- 老师单个学生跟进耗时
- 模板复用率
- 家长周报发送稳定性
