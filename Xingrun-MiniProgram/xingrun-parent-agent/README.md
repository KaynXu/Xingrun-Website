## 文档分工

- `docs/01-overview/`: 长期稳定的项目定位、目标、边界
- `docs/02-product/`: 功能模块、用户流、成功指标
- `docs/03-pilot/`: 当前试点，不同学科或场景各自单开文件
- `docs/04-operations/`: 规则、协作方式、文档系统
- `templates/`: 可直接复用的执行模板
- `references/`: 原始素材、来源映射、旧文档入口
- `archive/`: 失效方案、旧版本、不再作为当前事实的内容

## 当前状态

这个目录先承接第一阶段试点：`A-Level Business`。其他学科和学段后续作为并列 pilot 扩展，不要先混进同一份文档。
