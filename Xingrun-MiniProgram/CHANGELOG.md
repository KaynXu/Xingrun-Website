# Changelog

## v0.1.0 - 2026-03-13

首个可用版本，完成从“群聊收图”到“错题诊断与老师汇总”的闭环。

### Added

- 微信小程序房间聊天、多人实时广播
- 图片和文件上传
- 图片预览、文档打开
- OpenClaw 文本聊天接入
- OpenClaw 图片错题分析接入
- 错题诊断卡 UI
- 学生自查提交
- `/汇总` PDF 导出
- PDF overview、目录跳转、详情页原图
- 定时推题接口
- Git 仓库初始化与忽略规则

### Changed

- 汇总从文本表格演进到 PDF 日报
- 图片分析从不稳定的 responses 多模态尝试，切到本地 OpenClaw agent 视觉链路
- 卡片从“批改结果卡”收敛为“错题诊断卡”
- 房间管理改成持久房间号，不再因为成员离开就失效

### Current Scope

- 家长上传错题图
- AI 给出错误类型、知识点、建议下一步、老师关注等级
- 学生补填错因与备注
- 老师查看 PDF 汇总
- 支持定时推送指定题目到房间

### Known Limits

- 视觉识别效果依赖 OpenClaw 当前模型与本机环境
- 定时推题仅支持房间在线推送，不是微信订阅消息
- 真实“重复错”目前仍以 AI 判断为主，尚未完全基于历史数据回溯
